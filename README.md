# JUJU Margin Notes

Script supervision and continuity for the Mac. © JUJU VFX 2026.

**Download:** the latest `JUJU-Margin-Notes-<version>.zip` under [Releases](https://github.com/mikeparsonstv-rgb/JUJU-Margin-Notes/releases). Unzip, drag the app to Applications, open it. It checks for updates itself (Sparkle); or use JUJU Margin Notes › Check for Updates… whenever you like.

**The Holloway sample production:** `Holloway-Sample-<version>.zip` on the same release — a twelve-day drama a few scenes in, with takes, notes, lining, photos and the day's paperwork. Unzip it and open it from File › Open Production…, or let the app make its own copy with File › Open the Holloway Sample.

Requires macOS 15 or later on Apple silicon.

`appcast.xml` in this repository is the update feed the app reads; `releases/` holds each version's notes.
